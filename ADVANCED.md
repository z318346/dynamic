# dynamic 1.3
Native iOS app, iOS 17+. The Demo Lab and simulated capability switches are removed. Bundle identifiers match v1.2.

- Blank Live Activity, original interface and TikTok link.
- Island layout previews only, not device identity changes.
- Foundation Models chat on compatible devices (iOS 26+ and available model), not system Siri.
- Wallpaper and card artwork PNG export; apply wallpaper manually. Does not alter existing Wallet cards.
- Import issuer-signed Wallet passes with system approval.
- Local plist editor, format validation, backup and export.
- No sandbox escape, worse_query, hardware spoofing, protected system writes or unlocking unsupported Apple features.
- Unsigned IPA; signing and physical-device testing are required.
