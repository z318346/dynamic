# dynamic 1.3 Advanced (experimental branch)
Native-only feature lab. The stable main branch is unchanged.

- Blank Live Activity from 1.2.
- Model layouts are illustrative previews, not device spoofing.
- Foundation Models chat runs only when the actual Apple on-device model is available; it does not unlock Siri.
- PNG wallpaper and card artwork export. Wallpaper must be applied by the user; artwork does not modify payment cards.
- Import issuer-signed Wallet passes with native system review.
- No MobileGestalt changes, exploit, arbitrary system writes, or copied EnsWilde code.
- IPA is unsigned. Build and physical-device testing are separate steps.
